## 🚀 Featured Project: StudyAI
I recently built **StudyAI**, an intelligent learning assistant that transforms how students process information.

### 🧠 What is StudyAI?
StudyAI is an AI-powered tool that helps you learn faster by converting dense content into digestible study materials.
- **📝 MCQ Generator:** Instantly creates quizzes from your personal notes.
- **📄 Smart Summarizer:** Turns long paragraphs into clean, professional bullet points.
- **🎥 YouTube-to-Notes:** Automatically fetches transcripts and converts video lessons into study guides.
- **🎨 Concept Visualizer:** Generates Flowcharts and Mind Maps using Mermaid.js logic.

### 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Intelligence:** Groq AI / Llama 3.3
- **Data:** YouTube Transcript API
